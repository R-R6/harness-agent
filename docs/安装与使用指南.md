# Harness Agent —— 安装与使用指南（Windows）

> 首版 Windows 内部版。桌面端：会话浏览器（Claude/Codex 分组 + 全文搜索）
> + 监督闭环（Claude 干活 → Codex 审查 → 返工）+ MCP 健康检查。

## 一、安装（首次装）

**执行目录**：装完从开始菜单/桌面双击打开，不需要命令行。

1. 安装包位置：`F:\project\workspace-side\Harness_agent\src-tauri\target\release\bundle\nsis\`
   - 文件名形如：`Harness Agent_0.1.0_x64-setup.exe`
2. 双击安装包 → 一路「下一步」→ 完成
3. 打开应用：开始菜单搜 **Harness Agent**（或桌面快捷方式）

### ⚠️ 首次运行遇到「Windows 已保护你的电脑」

因为安装包**没有代码签名证书**（内部版没买证书），SmartScreen 会拦截：

```
Windows 已保护你的电脑
Microsoft Defender SmartScreen 已阻止启动一个未识别的应用
```

**处理步骤**（3 步）：
1. 点击 **「更多信息」**（在提示文字下方的小字链接）
2. 出现 **「仍要运行」** 按钮 → 点击
3. 应用启动，安装完成

> 说明：这是自签名/未签名应用的正常提示，不是病毒。
> 自己电脑上信任后，以后安装不再提示。

### 1. 会话浏览
- 左侧列表按 **Claude Code（橙）/ Codex（蓝）** 分组，显示会话标题 + 北京时间
- 顶部搜索框：按关键词搜**对话内容**（排除工具输出杂音），结果上方有「✕ 清除」
- 点会话看正文；右侧分割线可拖动调宽度

### 2. 监督闭环（核心功能）
1. 填**任务描述**（如"写一个猜数字游戏，要带输入校验"）
2. 选**工作目录**：输入框旁「📁 浏览」打开资源管理器选项目目录
3. 选**分级**（L0 最快 / L1 默认 / L2 最严）+ 勾选**模拟模式**（不花钱跑流程）
4. 点「启动监督闭环」→ 左侧实时日志流，右侧审查看板显示逐轮审查卡片
5. 闭环：**Claude 干活 → Codex 读真实会话审查 → 意见回灌 → 返工**，最多按分级轮数

> 真实模式需要本机已配置 `claude` / `codex` 命令行工具。
> 产物落在 `工作目录\.supervise\`（review-N.md + final-report.json）。

### 3. MCP 状态
- 检查 agent-sessions MCP 注册（Codex 桌面端重写 config.toml 会冲掉注册）
- 发现异常 → 点「一键修复」（自动备份 + 补注册段 + 原子写）
- 含真实握手验证（spawn node server.js 发 initialize）

## 三、常见问题

| 问题 | 解决 |
|---|---|
| SmartScreen 拦截 | 见上文「更多信息 → 仍要运行」 |
| 会话列表是空的 | 确认本机跑过 Claude Code / Codex（有 .claude/.codex 会话目录） |
| MCP 状态显示异常 | 点「一键修复」，改完**新开** Codex 会话生效 |
| 监督闭环卡住 | 点「取消」；真实模式首次跑较慢（Claude 干活 + Codex 审查） |

## 四、开发（开发者用）

```powershell
# 开发模式（热更新）
cd F:\project\workspace-side\Harness_agent
npm run tauri dev

# 重新打包
npm run tauri build
```

> 依赖：Rust GNU 工具链（见 rust-tauri-gnu-windows skill）+ Node。
> 注意 dev 端口 14200（1420 在 Windows Hyper-V 保留段）。
